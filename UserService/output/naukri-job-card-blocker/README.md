# Naukri Job Card Blocker

Chrome extension that hides Naukri job cards by visible text. Add `python`, and job cards containing Python will be hidden. Add company names like `Accenture`, and those cards will be hidden too.

## Install

1. Open Chrome.
2. Go to `chrome://extensions`.
3. Turn on `Developer mode`.
4. Click `Load unpacked`.
5. Select:
   `C:\Users\admin\OneDrive\Desktop\Codex made\naukri-job-card-blocker`
6. Refresh the Naukri jobs page.

## Use

1. Click the extension icon.
2. Add a skill, company, or keyword.
3. Example: `python`, `php`, `Accenture`, `WordPress`.
4. Matching job cards will hide automatically.

Use `Rescan` if Naukri loads more jobs after scrolling.
