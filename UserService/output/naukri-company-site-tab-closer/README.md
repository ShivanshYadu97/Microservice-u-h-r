# Naukri Company Site Tab Closer

Chrome extension for Naukri. It automatically closes a Naukri tab when the job detail page shows company-site apply text.

It watches for:

- `Apply on company site`
- `Apply to company site`
- `Apply on external site`
- `Apply to external site`

## Install

1. Open Chrome.
2. Go to `chrome://extensions`.
3. Enable `Developer mode`.
4. Click `Load unpacked`.
5. Select:
   `C:\Users\admin\OneDrive\Desktop\Codex made\naukri-company-site-tab-closer`
6. Refresh Naukri tabs.

## Use

Keep the extension enabled. Whenever a Naukri tab shows `Apply on company site`, that tab will close automatically.

The popup has:

- On/off toggle
- Close delay
- Manual scan button
