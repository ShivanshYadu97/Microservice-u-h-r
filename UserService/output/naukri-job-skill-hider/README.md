# Naukri Job Skill Hider

Chrome extension for hiding Naukri job cards that contain blocked skills or keywords.

## Install

1. Open Chrome and go to `chrome://extensions`.
2. Enable `Developer mode`.
3. Click `Load unpacked`.
4. Select this folder:
   `C:\Users\admin\OneDrive\Desktop\microservices\UserService\output\naukri-job-skill-hider`
5. Open or refresh Naukri search results.

## Use

1. In the floating `Naukri Skill Hider` box, enter skills separated by commas or new lines.
2. Example: `python, php, wordpress, .net`
3. Click `Save & scan`.
4. Matching job cards will be hidden automatically while scrolling.

Use `Clear` to remove filters, `Rescan` after Naukri loads more cards, and the `On` checkbox to pause/resume filtering.
