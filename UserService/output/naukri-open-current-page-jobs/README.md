# Naukri Open Current Page Jobs

Chrome extension that opens all job cards already loaded on the current Naukri results page.

It does not open next pages and does not auto-scroll. It only reads the cards currently loaded in the page DOM.

## Install

1. Open Chrome.
2. Go to `chrome://extensions`.
3. Enable `Developer mode`.
4. Click `Load unpacked`.
5. Select:
   `C:\Users\admin\OneDrive\Desktop\Codex made\naukri-open-current-page-jobs`
6. Refresh the Naukri results page.

## Use

1. Open a Naukri search results page.
2. Click the extension icon.
3. Check the job count.
4. Click `Open all jobs`.

Use `Open max tabs` to avoid opening too many tabs at once.
